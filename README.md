Pong Game (C++ & Raylib)
Проєкт класичної гри Pong, реалізований на мові C++ з використанням бібліотеки Raylib. Програма побудована на принципах об'єктно-орієнтованого програмування та використовує менеджер станів для керування ігровим процесом.

Функціонал гри
Режими гри: Підтримка одиночної гри проти штучного інтелекту та локального мультиплеєра для двох гравців.

Інтерфейс: Наявність головного меню з вибором режимів за допомогою інтерактивних кнопок.

Логіка: Автоматичне відстеження рахунку, обробка колізій з корекцією позиції м'яча та завантаження графічних текстур.

Керування
Правий гравець: Стрілки Вгору та Вниз для переміщення ракетки.

Лівий гравець: Клавіші W та S (активно у режимі на двох гравців).

Навігація: Клавіша Space для швидкого повернення з гри до головного меню.

Технічна частина
Для розробки використано стандарт C++ та графічну бібліотеку Raylib. Архітектура проєкту розділена на логічні блоки:

Класи об'єктів: Ball та Paddle відповідають за фізику та відображення м'яча і ракеток.

Клас Button: Обробляє стан кнопок та їх візуалізацію.

Клас Manager: Виконує роль координатора, який керує станами гри, оновленням даних та відмальовкою кадрів.

Збірка та запуск
Для запуску проєкту необхідно мати встановлену бібліотеку Raylib. Компіляція всіх файлів виконується однією командою:

g++ main.cpp Manager.cpp Ball.cpp Paddle.cpp Button.cpp -lraylib -o pong_game

Після збірки запустіть файл pong_game. Переконайтеся, що папка Graphics із ресурсами знаходиться в одній директорії з виконуваним файлом.
