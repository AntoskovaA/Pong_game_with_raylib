Pong Game (C++ & Raylib) 🏓
Проста та динамічна реалізація класичної гри Pong, написана на C++ з використанням графічної бібліотеки Raylib. Проєкт демонструє об'єктно-орієнтований підхід (ООП) та базову архітектуру ігрового рушія.

✨ Особливості
Два режими гри:

VS Bot: Гра проти штучного інтелекту.

2 Players: Локальний мультиплеєр для гри з другом.

Меню керування: Стартова сторінка з кнопками вибору режимів.

Автоматичний рахунок: Відстеження балів для обох сторін.

Адаптивність: Виштовхування м'яча при колізіях для уникнення багів.

🎮 Керування
Гравець 1 (праворуч): Стрілки Вгору / Вниз.

Гравець 2 (ліворуч): Клавіші W / S.

Меню: Повернення до головного меню натисканням Space.

🛠 Технології
Мова: C++

Бібліотека: Raylib 5.0+

Архітектура: Менеджер станів (State Machine), класи Ball, Paddle, Button, Manager.

🚀 Як запустити
Переконайтеся, що у вас встановлено Raylib.

Скомпілюйте проєкт (наприклад, через g++):

Bash
g++ main.cpp Manager.cpp Ball.cpp Paddle.cpp Button.cpp -lraylib -o pong_game
Запустіть файл:

Bash
./pong_game
📁 Структура проєкту
main.cpp — точка входу та ігровий цикл.

Manager — логіка перемикання екранів та координація об'єктів.

Paddle/Ball — фізика та візуалізація ігрових сутностей.

Graphics/ — папка з текстурами для фону та кнопок.
